# StayVista – Hotel Booking App UI/UX Design

##  Project Description

StayVista is a modern and user-friendly hotel booking mobile application designed in Figma. It helps users explore popular destinations, discover hotels, select rooms, and complete their hotel reservations through a simple and smooth booking experience.

The application features an elegant design with a green and gold color theme, creating a premium and attractive user interface.

##  Features

- Attractive welcome and home screens
- Search hotels by destination and travel dates
- Explore popular tourist destinations
- Browse hotels with prices, ratings, and details
- View hotel information and amenities
- Select rooms based on user preferences
- Enter booking and contact details
- Multiple payment methods
- Booking confirmation screen
- Simple and intuitive navigation

##  App Screens

1. **Home Page** – Welcome screen with the StayVista brand and Start Now button.
2. **First Page** – Search hotels and explore popular destinations.
3. **Second Page** – Browse hotels with ratings, prices, and details.
4. **Third Page** – View hotel details, amenities, and booking options.
5. **Fourth Page** – Select a room and review room amenities.
6. **Fifth Page** – Enter booking details and contact information.
7. **Sixth Page** – Choose a payment method and complete payment.
8. **Seventh Page** – View booking confirmation and reservation details.

##  Tools Used

- Figma
- UI/UX Design
- Prototyping

##  Project Objective

The main objective of StayVista is to provide a convenient and enjoyable hotel booking experience through an attractive, organized, and easy-to-use mobile app interface.

##  User Flow

Welcome Screen → Home Page → Hotel Listing → Hotel Details → Room Selection → Booking Details → Payment → Booking Confirmation
